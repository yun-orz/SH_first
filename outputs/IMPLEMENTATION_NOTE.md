# 当前实现说明

本目录中的 `baseline` 和 `scene_sweep` 是代码实际运行生成的第一版结果，不是论文最终数据。

当前解析环带螺旋 DOE 已经完成端到端验证，但尚未使用实验室真实器材参数，也未经过制造约束优化。因此：

- 点源基线用于确认模型、噪声、估计和评价链条能运行；
- 复杂场景热图用于暴露当前设计的优劣边界；
- 当前双通道没有表现出稳定优势是有效的负结果，说明必须先优化 DOE，再谈加工；
- 获得相机、镜头、分光器、光源和加工参数后，应先修改 `configs/baseline.yaml`，重新运行全部命令。

建议下一步先填写 `docs/equipment_checklist.md`，再运行 `optimize-seed` 选取更好的解析初值。
