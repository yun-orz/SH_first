# 研究执行与记录规范

## 一、先做什么

第一阶段不要加工 DOE。先运行默认基线，确认传播采样、编码曲线和 Fisher 信息计算正确；再用实验室真实焦距、孔径、像元和加工约束替换配置。解析环带螺旋相位只是优化初值，只有在量化、误差扰动和标定仿真均通过后才能提交加工。

## 二、每次仿真必须记录

- Git提交或代码版本、配置文件和随机种子；
- 波长范围、采样间隔、物距、像距、孔径、焦距和像元；
- DOE材料、口径、相位级数、最小特征和设计波长；
- 总入射光子数、分光比例、DOE效率、背景与读噪声；
- 比较采用等光子口径还是硬件真实口径；
- 每个条件的重复次数、失败样本和失败定义。

## 三、建议实验顺序

1. 无 DOE：测暗场、平场、像元响应和标准成像分辨率。
2. 点源标定：每个可用波长至少采集20帧，记录曝光、功率和温度。
3. 双通道配准：使用同一参考靶拟合仿射变换，并保存残差图。
4. 单点盲测：打乱波长顺序后估计，禁止手工挑选模板。
5. 多点与分块场景：逐渐增加目标密度和边界复杂度。
6. 鲁棒性实验：照度、背景、失配、离焦和带宽一次只改变一个变量。

## 四、公平比较红线

- 同一场景、波段、曝光时间和入射功率；
- 同时报告总入射光子对齐与实际探测光子两种结果；
- 总有效像素数相同，双通道不能暗中使用两倍裁剪面积；
- 估计器共享同一代价函数、搜索网格和标定样本；
- 不删除失败帧；异常值率必须单独报告。

## 五、DOE加工门槛

在以下条件全部满足前不加工：

- 量化相位下存在连续、无歧义的工作波段；
- 相邻目标波长的模板差异超过噪声引起的帧间差异；
- 制造深度误差蒙特卡洛后主要结论不反转；
- 双通道和基线均满足相同加工规则；
- 加工方已书面确认材料折射率、台阶数、最小线宽、深度误差和有效口径。
