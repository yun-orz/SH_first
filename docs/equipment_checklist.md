# 实验室器材与加工条件清单

开始实验前逐项填写；未知项必须通过铭牌、说明书或实测确认。

## 探测器

- 型号、数量：
- 单色/彩色：
- 像元尺寸、有效像素、位深：
- 量子效率曲线：
- 满阱容量、增益、读出噪声、暗电流：
- 是否支持外触发与双机同步：
- 可导出的原始格式：

## 光源与光谱标定

- 单色仪或可调谐光源型号：
- 可用激光/LED中心波长及FWHM：
- 窄带滤光片中心波长及FWHM：
- 光谱仪型号与波长准确度：
- 光功率计型号与测量范围：

## 成像光路

- 镜头焦距、口径、工作距离：
- 非偏振分光器型号、T/R曲线：
- 反射镜、位移台、针孔/光纤端面：
- 两臂可用空间及最长光程：

## DOE加工

- 材料及厂家折射率数据：
- 有效口径与基片尺寸：
- 相位/高度级数：
- 最小线宽：
- 最大刻蚀深度与深度误差：
- 横向尺寸误差、表面粗糙度：
- 是否提供轮廓仪或显微测量报告：
- 单片成本、周期和最小订单：
