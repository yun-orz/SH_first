# 三系统最小物理可行性验证

## 研究问题

在固定物距和相同总探测光子数下，比较单 DOE 双螺旋、单通道单螺旋和双通道共轭单螺旋的波长可分辨性。该实验只判断当前解析 DOE 初值是否显示信息收益，不证明最终优化后的性能。

## 公平性口径

- 三套系统使用相同 DOE 口径、波长网格、传播距离、像元尺寸、背景和读出噪声。
- 双螺旋和单通道单螺旋获得全部总信号光子。
- 双通道单螺旋的两路各获得 50% 信号光子，总和与基线相同。
- 双通道读取两幅传感器图，因此分别计入背景和读出噪声。
- 本实验比较固定裁剪窗口内、给定总探测光子条件下的编码形状，不比较 DOE 的绝对衍射效率。

## 指标定义

- Pearson相关系数：去均值后的PSF形态相关性。
- 余弦相似度：非负强度观测向量的夹角相似度。
- Fisher信息：采用泊松均值加高斯读噪声方差近似，双通道的信息逐通道相加。
- CRLB：输出波长估计标准差下界，单位为nm。
- 双螺旋旋转角：PSF二阶矩主轴方向，按180度周期表示。
- 单螺旋旋转角：PSF质心相对光轴的方位角，按360度周期表示。
- 双通道旋转角：两通道质心连线方向，按360度周期表示。

## 解释边界

若双通道的相关性更低、Fisher信息更高且CRLB更低，说明当前共轭设计具有继续优化价值。若其只在部分波段占优，结论应表述为证据混合。若等总光子下三项指标均不占优，应先优化DOE相位，不能直接进入加工或宣称双通道优越。
